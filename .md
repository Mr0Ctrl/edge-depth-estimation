# EdgeDepth-Lite: Real-Time Monocular Depth Estimation for Mobile Aperture Simulation

## 1. Problem Statement & Motivation
Mobile devices and low-cost robotic platforms rely on fixed-aperture lenses that cannot produce true physical depth of field (optical bokeh). While state-of-the-art foundation models (e.g., Depth Anything, MiDaS) produce high-fidelity dense depth maps, their Vision Transformer (ViT) backbones introduce prohibitive computational latency (>150 ms) and high thermal throttling on edge accelerators.

**Objective:** Design, train, and benchmark a parameter-efficient, fully convolutional monocular depth estimation network capable of producing metric/relative depth maps on edge hardware under tight inference budgets (<20 ms) for synthetic aperture and shallow depth-of-field synthesis.

---

## 2. Dataset & Target Pipeline
- **Dataset:** NYU Depth V2 (indoor scenes with structured depth boundaries) and KITTI (outdoor vehicle/obstacle profiles).
- **Inputs:** Single RGB frames downsampled to $256 \times 256$ or $320 \times 240$ with photometric augmentations (contrast, saturation, color jitter).
- **Ground Truth:** Aligned depth maps (raw sensor inputs with inpainting masking for valid regions).
- **Target Representation:** Inverse depth (disparity) maps $d = 1 / z$ normalized to $[0, 1]$ to stabilize near-field gradient backpropagation.

---

## 3. Architecture & Methodology

```
[ Input RGB: 3x256x256 ]
           │
           ▼
[ Encoder: MobileNetV3-Small / EfficientNet-B0 Backbone ]
           │ (Extract multi-scale features: C1, C2, C3, C4, C5)
           ▼
[ Latent Bottleneck: Dilated Convolutional ASPP Block ]
           │ (Capture large receptive fields without downsampling)
           ▼
[ Decoder: Lightweight Up-Projection with Skip Connections ]
           │ (Bilinear Upsample + Depthwise Separable Conv + PixelShuffle)
           ▼
[ Multi-Scale Feature Fusion Head ]
           │
           ▼
[ Output: Dense Relative Depth Map (1x256x256) ]
```

### Key Architectural Concepts
1. **Depthwise Separable Decoders:** Replace standard $3 \times 3$ transpose convolutions with inverted bottleneck blocks to minimize FLOPs.
2. **Composite Structural Loss:** Avoid the blurry edge artifacts produced by pure Mean Squared Error ($\mathcal{L}_{MSE}$):
   $$\mathcal{L}_{total} = \alpha \mathcal{L}_{depth} + \beta \mathcal{L}_{SSIM} + \gamma \mathcal{L}_{edge}$$
   - $\mathcal{L}_{depth}$: $L_1$ norm on valid depth values.
   - $\mathcal{L}_{SSIM}$: Structural Similarity Index to penalize structural distortion.
   - $\mathcal{L}_{edge}$: Edge-aware smoothness loss using image gradients to align depth discontinuities with RGB object borders.

## 5. Evaluation Metrics & Validation Strategy
- **Accuracy Metrics:**
  - Root Mean Squared Error (RMSE) and Absolute Relative Error (AbsRel).
  - Threshold Accuracy: Percentage of pixels satisfying $\max\left(\frac{y_i}{\hat{y}_i}, \frac{\hat{y}_i}{y_i}\right) = \delta < 1.25$.
- **Edge Deployment Metrics:**
  - Number of Parameters (M) & Multiply-Accumulate Operations (FLOPs).
  - Real hardware latency ($ms$) measured on NVIDIA Jetson Nano under FP32, FP16, and INT8 runtime configurations.

---

## 6. End-Use Deliverable
A standalone C++ or Python real-time demonstration pipeline taking a camera feed, estimating relative per-pixel depth, and applying a synthetic depth-of-field Gaussian/disc blur to non-focused depth planes.
